# Сканворды · v13

Шесть вручную составленных русских сканвордов 10×7. В каждом — 10 коротких газетных подсказок, 56 буквенных клеток и 4 явно серых неиспользуемых блока. Пустых белых клеток нет. Ответы и подсказки не повторяются между выпусками.

На телефоне сетка идёт сразу под шапкой во всю ширину и растягивается по высоте до строки выбранной подсказки. Сразу под подсказкой — два ряда букв, без пустой серой зоны; клетки с подсказками показывают весь текст. Сохранены каталог, локальный прогресс, необязательная системная клавиатура и подсказки.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=13

Проверка: `npm test`, `node tests/browser-smoke.cjs`, `node tests/offline-smoke.cjs` (для последнего нужен HTTP-сервер).
