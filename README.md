# Сканворды · v15

Шесть оригинальных русских сканвордов 10×7, по 12 слов в каждом. Только два направления заполнения: слева направо (→) и сверху вниз (↓); клетка с подсказкой непосредственно перед первой буквой. Оригинальные определения сохранены, сетки не скопированы с graycell.ru. Все 70 клеток каждой сетки — подсказка, буква или явный серый блок; слова пересекаются.

Геометрия v13 сохранена: сетка заполняет пространство между шапкой и строкой подсказки; два ряда букв сразу под строкой. Масштабируется вся сетка, доступны кнопки +/−, pinch и прокрутка увеличенного поля одним пальцем. За каждое разгаданное слово появляется цветной залп конфетти; за весь сканворд — большой залп.

Открыть: https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=15

Проверка: `npm test`, `node tests/browser-smoke.cjs`, `node tests/offline-smoke.cjs` (последнему нужен HTTP-сервер).
