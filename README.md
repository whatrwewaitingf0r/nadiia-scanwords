# Сканворды · v17

56 оригинальных русских сканвордов 10×7: первые шесть по 12 слов, ещё 50 по 8 слов. Только два направления заполнения: слева направо (→) и сверху вниз (↓); клетка с подсказкой непосредственно перед первой буквой. Оригинальные определения и геометрия первых шести сохранены, сетки не скопированы с graycell.ru. Все 70 клеток каждой сетки — подсказка, буква или явный серый блок; слова пересекаются.

Геометрия v13 сохранена: сетка заполняет пространство между шапкой и строкой подсказки; два ряда букв сразу под строкой. Масштабируется вся сетка, доступны кнопки +/−, pinch и прокрутка увеличенного поля одним пальцем. За каждое разгаданное слово появляется цветной залп конфетти; за весь сканворд — большой залп.

Открыть: https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=17

Проверка: `npm test`, `node tests/browser-smoke.cjs`, `node tests/offline-smoke.cjs` (последнему нужен HTTP-сервер).
Повторная раскладка исходных слов: `python3 scripts/reflow-v17.py` (нужны NumPy и SciPy); скрипт запрещает продолжения за концом ответа и требует общие буквы пересечений.

Новые выпуски №7–56 распределены по темам: биология, культуры стран, география, история, литература, музыка, кино, еда, наука, искусство, пословицы и общие знания. Авторский словарь: `data/v17-lexicon.txt`; детерминированная сборка: `python3 scripts/build-v17.py`. Генератор допускает только → и ↓, требует пересечения, запрещает продолжение слова за его концом, а остальные клетки отмечает блоками.

В новых выпусках 400 неповторяющихся ответов, из них 29% лёгких, 51% средних и 20% сложных; не менее трёх слов каждого выпуска относятся к его теме. На коротком экране iPhone SE в серой клетке показывается краткий фрагмент определения, а полная формулировка остаётся в строке подсказки и доступном названии кнопки. Первые шесть сеток и их определения не меняются.
