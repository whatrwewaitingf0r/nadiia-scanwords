# Сканворды · v4

Каталог из 90 оригинальных русских сканвордов: категории, статистика, чёрно-белые миниатюры и плотные сетки со словами по горизонтали и вертикали. В игре — две строки букв с ложными вариантами, сохранение прогресса, мягкая проверка без вспышек ошибки, искры за слово и конфетти за завершённую сетку.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=4

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080/?v=4`.

## Проверка

```bash
npm test
```
