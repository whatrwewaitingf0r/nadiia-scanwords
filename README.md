# Сканворды · v5

Каталог из 90 оригинальных русских сканвордов. Игровая сетка перестроена в газетный формат: 10×7 равных клеток на планшете, серые подсказки прямо в клетках и ответы, начинающиеся в соседней клетке по стрелке. На узком iPhone та же сетка поворачивается в 7×10, чтобы клетки были крупнее и поле не оставляло пустую высоту.

Каждая сетка занимает все 70 клеток: 12 клеток-подсказок и 58 буквенных клеток. Сохранены подсветка текущего слова, две строки из 20 букв с ложными вариантами, мягкая проверка без мгновенной ошибки, искры, конфетти, локальный прогресс и каталог №1–90.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=5

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080/?v=5`.

## Проверка

```bash
npm test
node tests/browser-smoke.cjs 'http://127.0.0.1:8080/?v=5'
```
