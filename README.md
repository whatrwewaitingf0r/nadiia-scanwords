# Сканворды · v18

56 оригинальных русских сканвордов 10×7, первые шесть — по 8 слов, новые 50 — по 6–7 слов. Заполнение только вправо (→) и вниз (↓). Первые шесть выпусков заново разложены из их собственных авторских определений; выпуски №7–56 собраны из авторского словаря. Сетки не копировались с graycell.ru.

**Правило v18:** две белые клетки с буквами соприкасаются стороной только тогда, когда обе входят в одно определённое слово. Настоящие пересечения →/↓ — общая буква двух слов. Между любыми другими соседними словами стоит серая клетка-блок; случайные пары букв, включая Ф/С, исключены. Каждая из 70 клеток — буква, подсказка или блок; длина выделения точно равна длине ответа.

Геометрия v16 сохранена: поле 10×7 заполняет место между шапкой и строкой подсказки; два ряда букв сразу под строкой. Кнопки +/−, pinch и прокрутка увеличенного поля одним пальцем работают как прежде. За слово и за весь сканворд появляются конфетти.

Открыть: https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=18

Проверка: `npm test`, `node tests/browser-smoke.cjs`, `node tests/offline-smoke.cjs` (последнему нужен HTTP-сервер). Детерминированная сборка: `python3 scripts/build-v18.py`. Исходные определения первых шести сеток сохранены в `data/v16-first-six.json`; словарь новых выпусков — `data/v17-lexicon.txt`.

Прогресс v16/v17 не переносится автоматически: координаты слов изменились, поэтому v18 использует отдельный ключ локального хранилища.
