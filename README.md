# Словолинии — русские сканворды

Оригинальная автономная игра: **48 готовых сканвордов** и режим «Новая сетка», который собирает новые варианты из словаря. Подсказки и ответы находятся прямо в сетке. Прогресс хранится только на устройстве в `localStorage`.

## Быстрый запуск

На Mac или ПК откройте файл `index.html` двойным щелчком. Сервер, установка и интернет не нужны.

Если браузер не разрешает локальные сценарии, откройте Терминал в этой папке и выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## iPhone / iPad: Safari и «На экран Домой»

Для полноценной иконки и автономного запуска iOS должна впервые открыть игру по **HTTPS** (страницы из приложения «Файлы» нельзя надёжно добавить на экран Домой, а обычный HTTP не даёт гарантированного офлайн-кэша).

1. Поместите всю папку на любой статический HTTPS-хостинг или домашний сервер с HTTPS. Никакой серверной логики не требуется.
2. На iPhone откройте адрес игры именно в **Safari**.
3. Дождитесь появления каталога, затем нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.
4. Запустите игру с новой иконки один раз при наличии сети. После этого файлы сохраняются в офлайн-кэше.

Для быстрой проверки в одной Wi‑Fi сети можно запустить на Mac `python3 -m http.server 8080` и открыть на iPhone `http://АДРЕС-MAC:8080`, но такой HTTP-вариант следует считать сетевым: iOS может не сохранить его для автономного запуска. Игра не отправляет данные и не требует серверной части.

## Управление

- Нажмите серую подсказку или белую клетку, чтобы выбрать слово.
- В пересечении повторное нажатие меняет горизонтальное/вертикальное слово.
- Вводите ответ плитками или русской клавиатурой.
- **Открыть букву** — показывает одну букву.
- **Убрать лишние** — оставляет только нужные плитки.
- **Открыть слово** — заполняет выбранное слово.

## Обновить каталог

Словарь находится в `data/words.json`. После изменений выполните:

```bash
npm run generate
npm test
```

Скрипт заново создаст 48 сеток в `data/puzzles.json` и JS-обёртки для запуска через `file://`.
