# Сканворды · v11

Восемь вручную курированных русских газетных сканвордов 10×7. Каждая клетка занята: 15 коротких подсказок со стрелками →, ↓, ← и 55 буквенных клеток. Это настоящая заполненная сетка, не редкие слова на белом поле.

Клетки квадратные и занимают всю доступную ширину. Строка подсказки однострочная; панель букв — ровно два компактных ряда по 44 px, прижата к низу. На узком телефоне квадратная сетка 10×7 математически не может занимать 55–60% высоты экрана; здесь приоритет — полная ширина и непрерывная плотная сетка.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=11

Локальная проверка: `npm test`, затем `python3 -m http.server 8080` и `node tests/browser-smoke.cjs 'http://127.0.0.1:8080/?v=11'`.
