# Сканворды · v8

Семь оригинальных русских сканвордов без повторяющихся ответов. В каждой сетке 10×14 размещено 24–25 слов с настоящими пересечениями и короткими газетными определениями. Серые клетки подсказок рассеяны по всему полю; в одной клетке могут жить две независимые подсказки со стрелками →, ← и ↓.

Размер клетки вычисляется в рантайме как `min(availableWidth / cols, availableHeight / rows)` без прежнего округления вниз. Высота 14 строк забирает свободное место экрана, а два ряда букв стоят последними — прямо над нижней safe area. Пустые буквенные клетки остаются белыми; подсвечивается только позиция ввода.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=8

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080/?v=8`.

npm test
