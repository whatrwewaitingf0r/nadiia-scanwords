# Сканворды для ума и языка · v3

Оригинальный автономный сканворд для Nadiia: плотная сетка, 17 тематических категорий, три уровня сложности, 20 крупных буквенных плиток, системная клавиатура, мягкие подсказки, сохранение прогресса и конфетти после завершения.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=3

## Локальный запуск

Откройте `index.html` в браузере или запустите:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/?v=3`.

## Проверка

```bash
npm test
```
