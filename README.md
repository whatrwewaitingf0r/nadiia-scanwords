# Сканворды · v7

Семь оригинальных русских сканвордов без повторяющихся ответов. Игровой экран повторяет плотную композицию классического планшетного сканворда: тонкая панель действий, сетка 10×7 из равных квадратов, рассеянные серые подсказки со стрелками →, ← и ↓, полноширинная строка текущей подсказки и два ряда из 20 букв с приманками.

Размер клетки вычисляется в рантайме как `min(availableWidth / cols, availableHeight / rows)`. Сетка непосредственно примыкает к строке подсказки и сохраняет 10×7 на iPhone и планшете. Пустые буквенные клетки остаются белыми; подсвечивается только позиция ввода.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=7

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080/?v=7`.

npm test
