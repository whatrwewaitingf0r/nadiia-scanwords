# Сканворды · v14

Шесть авторских русских сканвордов 10×7. В каждом — 12 коротких газетных подсказок по горизонтали и вертикали; слова реально пересекаются общими буквами (2–3 пересечения на сетку). Пустых белых клеток и повторяющихся ответов или подсказок нет. Определения сочетают быт, природу, географию и культуру; все написаны специально для проекта. graycell.ru использовался только как образец стиля, без копирования сеток, ответов или текстов. Коммерческие наборы не использовались.

Геометрия v13 сохранена: на телефоне сетка идёт сразу под шапкой во всю ширину и растягивается по высоте до строки выбранной подсказки. Сразу под подсказкой — два ряда букв, без пустой серой зоны; клетки с подсказками показывают весь текст. Сохранены каталог, локальный прогресс, необязательная системная клавиатура и подсказки.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=14

Проверка: `npm test`, `node tests/browser-smoke.cjs`, `node tests/offline-smoke.cjs` (для последнего нужен HTTP-сервер).
