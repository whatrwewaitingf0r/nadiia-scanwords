# Сканворды · v9

Семь оригинальных русских сканвордов без повторяющихся ответов. В каждой сетке теперь 7×10 крупных клеток и ровно 12 коротких газетных определений: меньше слов, зато подсказки и буквы заметно крупнее и легче читаются на iPhone.

По умолчанию поле целиком помещается на экране. Буквы набраны кеглем 22–28 px, текст в клетках подсказок — от 14 px. Поле можно увеличить двумя пальцами или видимыми кнопками «− мельче» / «+ крупнее» в верхней панели; увеличенную сетку можно прокручивать.

Два ряда букв остаются последним элементом интерфейса и прилегают к нижнему краю без бежевого зазора. Сохранены каталог, локальный прогресс, подсказки без штрафа, вспышка за слово и конфетти за весь сканворд.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=9

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080/?v=9`.
