# Сканворды · v10

Десять вручную собранных русских сканвордов. Каждый экран — газетный блок **10×7**: все 70 клеток заняты либо короткой подсказкой, либо буквой. Серые клетки рассеяны по полю; ответы начинаются сразу после стрелки →, ← или ↓.

На телефоне размер клетки вычисляется как `min(availableWidth / 10, availableHeight / 7)`. Сетка касается тонкой шапки и строки текущей подсказки, а два ряда крупных букв занимают всю оставшуюся ширину до нижнего края. Подсказки внутри клеток показываются полностью, без многоточий.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=10

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080/?v=10`.
