# Сканворды · v12

Шесть вручную составленных русских сканвордов 10×7. В каждом — 10 коротких газетных подсказок, 56 буквенных клеток и 4 явно серых неиспользуемых блока. Пустых белых клеток нет. Ответы и подсказки не повторяются между выпусками.

На телефоне сетка квадратных клеток идёт сразу под шапкой во всю ширину; строка выбранной подсказки примыкает к ней. Остальная площадь — сплошная серая клавиатурная зона с двумя компактными рядами букв у нижнего края. Сохранены каталог, локальный прогресс, необязательная системная клавиатура и подсказки.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=12

Проверка: `npm test`, `node tests/browser-smoke.cjs`, `node tests/offline-smoke.cjs` (для последнего нужен HTTP-сервер).
