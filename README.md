# Сканворды · v6

Каталог из 90 оригинальных русских сканвордов. Игровая сетка — 10×7 равных клеток на любом экране. Серые клетки с подсказками рассеяны по всему полю, а ответы →, ← и ↓ начинаются сразу за стрелкой.

Генератор использует 12 плотных шаблонов точного покрытия: каждая из 70 клеток является либо реальной подсказкой, либо буквой ответа. Пустых и декоративных клеток нет. Например, «№2 · Биология»: 10×7, 12 подсказок, 58 букв, 0 пустых клеток; подсказки занимают 7 строк и 7 столбцов.

На iPhone поле больше не поворачивается в узкую башню 7×10. Размер квадратной клетки считается как `min(ширина / 10, высота / 7)`, поэтому сетка заполняет ширину экрана. Сохранены подсветка текущего слова, нижняя строка подсказки и два ряда букв.

**Открыть:** https://whatrwewaitingf0r.github.io/nadiia-scanwords/?v=6

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080/?v=6`.
